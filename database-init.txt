# Database Setup Commands - From Clean State to Successful Login

## Complete Working Sequence

These are the exact commands that worked to set up the database from scratch and get a working login.

---

## Step 1: Start All Containers

```bash
cd /mnt/e/Courses/test/MIP-WA-CRM

# Start all services
docker compose up -d

# Wait for containers to be ready
sleep 10

# Check status (all should be running)
docker compose ps
```


## Complete One-Line Script (Run Everything at Once)

```bash
cd /mnt/e/Courses/test/MIP-WA-CRM && \
docker compose up -d && \
sleep 10 && \
docker compose exec -T postgres psql -U postgres -d mavoid_crm < backend/prisma/migrations/20260511144433_init/migration.sql && \
docker compose exec postgres psql -U postgres -d mavoid_crm -c "\dt" && \
curl -X POST http://localhost:3001/api/v1/auth/register -H "Content-Type: application/json" -d '{"email":"newadmin@mavoid.com","password":"password123","name":"New Admin","role":"ADMIN"}' && \
echo "" && \
curl -X POST http://localhost:3001/api/v1/auth/login -H "Content-Type: application/json" -d '{"email":"newadmin@mavoid.com","password":"password123"}'
```

---

## Why This Works (Not Other Methods)

| Method | Result | Why |
|--------|--------|-----|
| Direct SQL INSERT | ❌ Login fails | Password hash format mismatch (`$2a$` vs `$2b$`) |
| Prisma migrate deploy | ❌ Fails | Prisma 7 config issues |
| Prisma db push | ❌ Fails | Requires proper datasource config |
| **Register via API** | ✅ **Works** | Backend uses correct bcrypt hashing |

## Troubleshooting Commands

### Check if backend is running
```bash
curl http://localhost:3001/api/v1/health
# Expected: {"status":"ok","uptime":...}
```

### Check if frontend can reach backend
```bash
docker compose exec frontend wget -qO- http://backend:3001/api/v1/health
```

### View backend logs
```bash
docker compose logs backend --tail=30
```

### Restart containers if needed
```bash
docker compose restart backend
docker compose restart frontend
```

### Complete reset (start over)
```bash
docker compose down -v
docker compose up -d
sleep 10
# Then run the migration and register commands above
```
